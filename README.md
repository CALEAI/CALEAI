# CALE-AI 2027 Workshop Website

This repository contains the static GitHub Pages website for the CALE-AI 2027 workshop:

CALE-AI 2027 — Evaluating AI Interventions: Causal and Longitudinal Human Effects

## Project

This website is designed for the AAAI-27 workshop and is intended to be hosted directly through GitHub Pages without any build system or backend.

## Local editing

Organizers can edit the following files directly:

- `index.html`
- `style.css`
- `script.js`

The site is intentionally lightweight and uses plain HTML, CSS, and minimal JavaScript.

## Important fields to update

Before publishing or sharing the site, organizers should update:

- workshop date
- submission URL
- final submission instructions
- speaker information
- program details
- program committee members
- organizer photos
- final AAAI conference links

## GitHub Pages deployment

To publish the site on GitHub Pages:

1. Go to repository Settings.
2. Open Pages.
3. Select “Deploy from a branch”.
4. Select `main`.
5. Select `/root`.
6. Save.

The site will be available at a URL similar to:

https://USERNAME.github.io/cale-ai-2027/

## Notes

- The site is designed to be easy to maintain by editing HTML and CSS directly.
- Placeholder content is marked clearly with comments for later updates.
- No Node.js, build tooling, or dependency installation is required.
